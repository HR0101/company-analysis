# パターン別・出力テンプレート＆フレームワーク集（Output Templates）

本リファレンスは、ユーザーが選択したパターン（業界 × 希望職種 × 選考フェーズ × 応募者属性 × 企業タイプ）に応じて出力するレポートおよび選考対策シートの標準フォーマットを定義する。

---

## 1. パターン選択メニュー（条件未指定時のクイックヒアリング用テンプレート）

ユーザーが「〇〇社の企業分析をして」「企業分析を手伝って」とだけ依頼し、パターンが未指定の場合は、以下のメニューを簡潔に提示して選んでもらう（または企業名から業界・企業タイプを自動推定した上で、職種と何次面接かを尋ねる）。

```markdown
### 🎯 企業分析＆選考対策パターン設定

対象企業（または業界）に合わせて最適な分析を行います。以下の項目から該当するものを教えてください（番号やキーワードだけでOKです。「おまかせ」の場合はフル分析を行います）。

1. **対象企業名・競合企業名**
   - 対象企業：（例：〇〇株式会社）
   - 比較したい競合：（未指定なら自動で主要競合2〜3社を選定します）
2. **業界パターン**（企業名から自動判定可能）
   - `A` IT・SaaS・Web・AI・SIer / `B` コンサル・シンクタンク / `C` メーカー（電機・自動車・化学・食品・製薬等） / `D` 商社（総合・専門） / `E` 金融（銀行・証券・保険・カード・運用） / `F` 広告・メディア・エンタメ・ゲーム / `G` 不動産・デベロッパー・建設・インフラ・物流 / `H` 人材・小売・EC・医療・教育・サービス
3. **希望職種パターン**
   - `1` 営業・CS系（法人/個人/IS/FS/CS）
   - `2` 企画・マーケ・事業開発系（経営企画/商品企画/マーケ/BizDev）
   - `3` PdM・PM・コンサルタント系
   - `4` ソフトウェア・AI・データエンジニア系
   - `5` 研究開発（R&D）・機電・化学・生産技術系
   - `6` コーポレート系（経理財務/人事/法務/広報IR）
4. **現在の選考フェーズ（何次面接か）**
   - `0` インターン・OB/OG訪問・カジュアル面談前
   - `1` 書類選考・ES・職務経歴書作成
   - `2` **1次面接**（人事・若手〜中堅現場社員向け）
   - `3` **2次・中盤面接**（現場課長・部長・マネージャー向け）
   - `4` **最終・役員面接**（社長・役員・事業本部長向け）
   - `5` 内定後・オファー面談・複数社内定比較
5. **応募区分**
   - `新卒`（学部・修士・博士） / `中途`（経験者転職） / `第二新卒`
```
